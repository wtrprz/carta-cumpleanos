# 🎂 Carta Digital de Cumpleaños

Una carta digital interactiva hecha con HTML, CSS y JavaScript para regalar a una amiga especial.

### Características
- Pantalla de entrada con un monito y botón "Abrir"
- Mensaje grande y emotivo
- Galería de fotos
- Decoraciones flotantes de monitos, hamsters y dibujitos
- Diseño 100% responsive (se ve bien en celular)

### Cómo usarlo

1. Clona o descarga este repositorio
2. Abre la carpeta en VS Code
3. Coloca tus fotos en la carpeta `images/`
4. Abre el archivo `index.html` con Live Server
